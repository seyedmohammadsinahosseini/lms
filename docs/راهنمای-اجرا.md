# راهنمای اجرای LMS روی سیستم خودتان

این نسخه یک برنامهٔ واقعی «کلاینت + سرور» است: Flutter رابط کاربری را اجرا
می‌کند و PHP/MariaDB داده را نگه می‌دارند. فقط بازکردن فایل HTML یا اجرای Flutter
بدون API کافی نیست.

## مسیر پیشنهادی برای ویندوز (XAMPP)

### ۱) پیش‌نیازها

- XAMPP با PHP 8.2 یا جدیدتر و MySQL/MariaDB
- Flutter 3.47.6 یا نسخهٔ stable سازگار
- Chrome برای تست سریع؛ Android Studio برای گوشی/شبیه‌ساز

افزونه‌های `pdo_mysql` و `mbstring` در `php.ini` باید فعال باشند. پس از تغییر،
Apache را Restart کنید.

### ۲) ساخت دیتابیس تازه

در phpMyAdmin یک دیتابیس با نام `lms` و collation برابر
`utf8mb4_unicode_ci` بسازید. سپس فقط فایل `backend/schema.sql` را Import کنید.
اگر دیتابیس قدیمی و واقعی دارید، schema تازه را روی آن Import نکنید؛ بخش مهاجرت
در README را بخوانید.

### ۳) تنظیم PHP

پروژه را مثلاً در `C:\xampp\htdocs\lms` قرار دهید. فایل زیر را بسازید:

```text
C:\xampp\htdocs\lms\config\lms.env
```

نمونهٔ محلی:

```dotenv
LMS_APP_ENV=local
LMS_APP_KEY=یک-رشته-تصادفی-طولانی-حداقل-۳۲-کاراکتر
LMS_DB_HOST=127.0.0.1
LMS_DB_PORT=3306
LMS_DB_NAME=lms
LMS_DB_USER=root
LMS_DB_PASS=
LMS_PUBLIC_BASE_URL=http://127.0.0.1/lms/backend
LMS_STORAGE_PATH=C:\xampp\lms-private\uploads
LMS_ALLOWED_ORIGINS=http://127.0.0.1:3000,http://localhost:3000
LMS_TRUST_PROXY=0
LMS_DEMO_MODE=1
LMS_ALLOW_TEACHER_REGISTRATION=1
LMS_LIVE_PROVIDER=jitsi
LMS_JITSI_BASE_URL=https://meet.jit.si
```

پوشهٔ `C:\xampp\lms-private\uploads` را بسازید. این پوشه عمداً داخل `htdocs`
نیست. حالا این آدرس باید JSON سالم برگرداند:

```text
http://127.0.0.1/lms/backend/api/v1/health.php
```

### ۴) اجرای Flutter Web

```powershell
cd C:\xampp\htdocs\lms\lms_flutter
flutter pub get
flutter run -d chrome --web-port=3000 `
  --dart-define=LMS_API_BASE=http://127.0.0.1/lms/backend/api/v1 `
  --dart-define=LMS_APP_MODE=development
```

### ۵) اجرای Android Emulator

آدرس `127.0.0.1` داخل emulator به خود emulator اشاره دارد. برای XAMPP روی همان
کامپیوتر از `10.0.2.2` استفاده کنید:

```powershell
flutter run -d emulator-5554 `
  --dart-define=LMS_API_BASE=http://10.0.2.2/lms/backend/api/v1 `
  --dart-define=LMS_APP_MODE=development
```

نسخهٔ release اندروید HTTP بدون رمزنگاری را قبول نمی‌کند؛ انتشار واقعی باید
HTTPS داشته باشد.

## لینوکس/macOS بدون XAMPP

```bash
mysql -u root -p -e 'CREATE DATABASE lms CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci'
mysql -u root -p lms < backend/schema.sql
mkdir -p config "$HOME/lms-storage/uploads"
cp backend/.env.example config/lms.env
# config/lms.env را برای local و مسیرهای سیستم خودتان ویرایش کنید
php -S 0.0.0.0:8080 -t backend
```

در ترمینال دوم:

```bash
cd lms_flutter
flutter pub get
flutter run -d chrome \
  --dart-define=LMS_API_BASE=http://127.0.0.1:8080/api/v1 \
  --dart-define=LMS_APP_MODE=development
```

## دادهٔ نمونهٔ محلی

فقط روی دیتابیس تازه و غیرتولیدی:

```bash
mysql -u root -p lms < tools/demo_seed.sql
```

ورودها:

- `teacher@lms.test` / `password`
- `student@lms.test` / `password`

در دمو آنلاین این seed استفاده نمی‌شود؛ دکمهٔ **Try demo** یک sandbox جدا و
منقضی‌شونده می‌سازد.

## تست‌ها

برای تست‌های API دو دیتابیس تمیز جدا (`lms_test` و `lms_security`) از روی
`backend/schema.sql` بسازید و سپس:

```bash
LMS_DB_NAME=lms_test bash tools/api_test.sh
LMS_DB_NAME=lms_security bash tools/api_security_test.sh
cd lms_flutter
flutter analyze
flutter test
```

اسکریپت‌های API خودشان PHP development server را روشن و خاموش می‌کنند.

## خطاهای رایج

- **`could not find driver`**: افزونهٔ PDO MySQL فعال نیست.
- **`Call to undefined function mb_*`**: افزونهٔ `mbstring` فعال نیست.
- **CORS در مرورگر**: origin دقیق مرورگر را در `LMS_ALLOWED_ORIGINS` اضافه کنید
  و سرور PHP را دوباره اجرا کنید.
- **گوشی API را نمی‌بیند**: از IP شبکهٔ کامپیوتر استفاده و پورت Apache/PHP را در
  فایروال باز کنید؛ جزئیات در `اجرا-روی-گوشی.md` است.
- **ثبت‌نام معلم در production رد می‌شود**: این رفتار امنیتی است؛ دعوت یک‌بارمصرف
  بسازید یا فقط در local مقدار `LMS_ALLOW_TEACHER_REGISTRATION=1` بگذارید.
- **Live در production خطای تنظیمات می‌دهد**: JaaS لازم است. `meet.jit.si` فقط
  برای توسعهٔ غیرتولیدی مجاز است.
