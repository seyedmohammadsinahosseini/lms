# راهنمای اجرای پروژه OTMS روی سیستم خودتان

این راهنما قدم‌به‌قدم و به فارسی توضیح می‌دهد چطور پروژه را روی ویندوز (و در
انتها لینوکس/مک) بالا بیاورید. اگر فقط می‌خواهید سریع شروع کنید، بخش
«خلاصه در ۵ قدم» کافی است.

**پیش‌نیاز کلی:** این پروژه دو تکه است — یک **سرور** (PHP + MySQL) و یک
**اپ موبایل/وب** (Flutter). هر دو باید بالا باشند تا اپ کار کند. اگر سرور بالا
نباشد، اپ با پیام «Could not reach the server at …» خطا می‌دهد.

---

## خلاصه در ۵ قدم (ویندوز + XAMPP)

```bat
:: ۱. پروژه را داخل htdocs بگذارید — نام پوشه باید OTMS1 باشد
cd C:\xampp\htdocs
git clone https://github.com/seyedmohammadsinahosseini/my_flutter_app.git OTMS1

:: ۲. در XAMPP Control Panel دکمه Start را برای Apache و MySQL بزنید

:: ۳. دیتابیس را بسازید
C:\xampp\mysql\bin\mysql.exe -u root < C:\xampp\htdocs\OTMS1\backend\schema.sql

:: ۴. اپ را اجرا کنید
cd C:\xampp\htdocs\OTMS1\otms_flutter
flutter pub get
flutter run -d chrome --dart-define=OTMS_API_BASE=http://localhost/OTMS1/backend
```

**۵. ورود با حساب‌های آماده:**

| ایمیل | رمز | نقش |
|---|---|---|
| `teacher@otms.test` | `password` | استاد |
| `student@otms.test` | `password` | دانش‌آموز |

اگر همه چیز درست باشد، صفحهٔ لاگین می‌آید و با حساب استاد وارد می‌شوید.

## قدم ۱ — پروژه را کجا بگذاریم؟ (مهم‌ترین نکته)

اپ به‌صورت پیش‌فرض آدرس بک‌اند را `http://localhost/OTMS1/backend` فرض می‌کند.
این آدرس یعنی: **پوشهٔ پروژه باید دقیقاً `OTMS1` نام داشته باشد و داخل `htdocs`
باشد.**

```
C:\xampp\htdocs\OTMS1\           ← نام پوشه باید OTMS1 باشد
├── backend\                     ← سرور (PHP)
└── otms_flutter\                ← اپ (Flutter)
```

پس:

```bat
cd C:\xampp\htdocs
git clone https://github.com/seyedmohammadsinahosseini/my_flutter_app.git OTMS1
```

اگر پوشه را جای دیگری گذاشتید (یا اسم دیگری دارد) مشکلی نیست — فقط موقع اجرای
اپ آدرس را دستی بدهید:

```bat
flutter run -d chrome --dart-define=OTMS_API_BASE=http://localhost/مسیر-شما/backend
```

> اگر پوشه‌ای به نام `OTMS1` از قبل دارید و نمی‌خواهید پاک شود: پروژه را جای
> دیگری clone کنید و فقط پوشه‌های `backend` و `otms_flutter` را داخل آن کپی
> کنید.

## قدم ۲ — Apache و MySQL را روشن کنید

**XAMPP Control Panel** را باز کنید و کنار **Apache** و **MySQL** دکمهٔ **Start**
را بزنید. هر دو باید سبز شوند.

**اگر Apache سبز نشد** (پورت 80 اشغال است): معمولاً Skype، IIS یا یک سرویس
دیگر پورت 80 را گرفته. یا آن برنامه را ببندید، یا در XAMPP:
`Config → httpd.conf` خط `Listen 80` را به `Listen 8080` و
`ServerName localhost:80` را به `localhost:8080` تغییر دهید. در این حالت آدرس‌ها
می‌شوند `http://localhost:8080/OTMS1/backend`.

## قدم ۳ — دیتابیس را بسازید

فایل `backend\schema.sql` خودش دیتابیس `otms`، هر ۱۶ جدول و چند دادهٔ نمونه
را می‌سازد.

### روش الف — خط فرمان

```bat
C:\xampp\mysql\bin\mysql.exe -u root < C:\xampp\htdocs\OTMS1\backend\schema.sql
```

اگر رمز برای `root` گذاشته‌اید:

```bat
C:\xampp\mysql\bin\mysql.exe -u root -p < C:\xampp\htdocs\OTMS1\backend\schema.sql
```

> ⚠️ **اگر از PowerShell استفاده می‌کنید**، علامت `<` کار نمی‌کند (خطای
> `The '<' operator is reserved`). این‌طور بنویسید:
> ```powershell
> cmd /c "C:\xampp\mysql\bin\mysql.exe -u root < C:\xampp\htdocs\OTMS1\backend\schema.sql"
> ```

### روش ب — بدون خط فرمان (راحت‌تر)

1. <http://localhost/phpmyadmin> را باز کنید
2. تب **Import** را بزنید
3. فایل `C:\xampp\htdocs\OTMS1\backend\schema.sql` را انتخاب کنید
4. **Go** را بزنید

### چک کردن موفقیت

در phpMyAdmin سمت چپ باید دیتابیس `otms` با ۱۶ جدول ببینید. یا:

```bat
C:\xampp\mysql\bin\mysql.exe -u root -e "USE otms; SELECT email, role FROM users;"
```

باید دو کاربر `teacher@otms.test` و `student@otms.test` را ببینید.

## قدم ۴ — چک کنید بک‌اند سالم است

این آدرس را در مرورگر باز کنید:

```
http://localhost/OTMS1/backend/api/me.php
```

پاسخ درست این است:

```json
{"error":"Not authenticated"}
```

این پاسخ **خوب** است و یعنی سه چیز درست کار می‌کند:

1. Apache پروژه را سرو می‌کند ✅
2. PHP به دیتابیس وصل می‌شود ✅
3. endpoint احراز هویت را چک می‌کند ✅

### اگر چیز دیگری دیدید

| خروجی | یعنی | راه‌حل |
|---|---|---|
| `{"error":"Database unavailable."}` | PHP به MySQL وصل نشد | MySQL در XAMPP روشن است؟ اگر رمز دارید `OTMS_DB_PASS` را تنظیم کنید (پایین‌تر) |
| `Table 'otms.login_attempts' doesn't exist` | دیتابیس شما قدیمی است | مایگریشن را اجرا کنید (پایین‌تر) |
| صفحهٔ خطای PHP یا متن HTML | خطای PHP یا `.htaccess` | لاگ را ببینید: `C:\xampp\apache\logs\error.log` |
| صفحهٔ سفید | معمولاً خطای کشندهٔ PHP | همان لاگ |

> **دیتابیس قدیمی؟** اگر `otms` را قبلاً ساخته بودید (قبل از تغییر
> محدودیت ورود)، یک بار این را اجرا کنید وگرنه ورود به سیستم خطا می‌دهد:
> ```bat
> C:\xampp\mysql\bin\mysql.exe -u root otms < C:\xampp\htdocs\OTMS1\backend\migrations\2026-09-15_login_attempts.sql
> ```

## قدم ۵ — اپ Flutter را اجرا کنید

اول مطمئن شوید Flutter نصب است:

```bat
flutter doctor
```

باید Flutter و (برای اندروید) Android toolchain سبز باشند. سپس:

```bat
cd C:\xampp\htdocs\OTMS1\otms_flutter
flutter pub get
```

### اجرا در مرورگر (سریع‌ترین راه برای تست)

```bat
flutter run -d chrome --dart-define=OTMS_API_BASE=http://localhost/OTMS1/backend
```

> پارامتر `--dart-define` اینجا **الزامی** است. چون dev server فلاتر روی یک پورت
> تصادفی اجرا می‌شود و وب اپ نمی‌تواند حدس بزند بک‌اند کجاست.

### اجرا روی شبیه‌ساز اندروید

```bat
flutter run
```

**بدون هیچ پارامتری.** اپ روی اندروید به‌طور خودکار از `http://10.0.2.2`
استفاده می‌کند که آدرس ماشین خودتان از دید شبیه‌ساز است. (اگر `localhost`
بدهید، شبیه‌ساز به خودش اشاره می‌کند و کار نمی‌کند.)

### اجرا روی گوشی واقعی (وصل به Wi-Fi)

۱. IP کامپیوتر خود را پیدا کنید:

```bat
ipconfig
```

در بخش کارت شبکهٔ Wi-Fi، مقدار `IPv4 Address` را بردارید — مثلاً `192.168.1.15`

۲. مطمئن شوید گوشی و کامپیوتر به **یک شبکه** وصل باشند.

۳. اگر ویندوز فایروال هشدار داد، اجازهٔ دسترسی Apache روی شبکهٔ **Private** را
بدهید.

۴. اجرا:

```bat
flutter run --dart-define=OTMS_API_BASE=http://192.168.1.15/OTMS1/backend
```

> ❗ روی گوشی واقعی `localhost` را ندهید — `localhost` روی گوشی یعنی خودِ گوشی.

### با VS Code

فایل `.vscode/launch.json` از قبل آماده است. کافی است پوشهٔ پروژه را در VS Code
باز کنید و <kbd>F5</kbd> بزنید و یکی از سه حالت را انتخاب کنید:

- `OTMS - Chrome (XAMPP on localhost)`
- `OTMS - Android emulator`
- `OTMS - physical device (edit the IP)` ← اول IP را داخل فایل عوض کنید

## تنظیمات (وقتی پیش‌فرض‌ها به کارتان نمی‌آید)

### سمت اپ

آدرس بک‌اند یک تنظیم **زمان بیلد** است، یعنی بعد از بیلد قابل تغییر نیست:

```bat
flutter run   --dart-define=OTMS_API_BASE=http://192.168.1.15/OTMS1/backend
flutter build apk --dart-define=OTMS_API_BASE=https://example.com/otms/backend
```

| پلتفرم | پیش‌فرض وقتی پارامتر ندهید |
|---|---|
| وب | همان origin که اپ از آن سرو شده |
| اندروید | `http://10.0.2.2` |
| بقیه (دسکتاپ، iOS simulator) | `http://localhost` |

و در همهٔ موارد `/OTMS1/backend` به آخرش اضافه می‌شود.

### سمت سرور

پیش‌فرض‌ها با XAMPP استاندارد جور است، پس برای کار لوکال چیزی لازم نیست. ولی
هر مقدار از environment قابل override است تا رمز داخل کد نماند:

| متغیر | پیش‌فرض | کاربرد |
|---|---|---|
| `OTMS_DB_HOST` | `127.0.0.1` | هاست دیتابیس |
| `OTMS_DB_NAME` | `otms` | نام دیتابیس |
| `OTMS_DB_USER` | `root` | کاربر دیتابیس |
| `OTMS_DB_PASS` | خالی | رمز دیتابیس |
| `OTMS_ALLOWED_ORIGINS` | خالی | origin های اضافی CORS (با کاما) |

**در Apache** — فایل `C:\xampp\apache\conf\extra\httpd-vhosts.conf` یا
`httpd.conf`، داخل بلوک `<VirtualHost>` یا `<Directory>`:

```apache
SetEnv OTMS_DB_PASS "رمز-شما"
SetEnv OTMS_ALLOWED_ORIGINS "https://otms.example.com"
```

بعد Apache را Restart کنید.

**در سرور CLI:**

```bash
OTMS_DB_PASS="رمز-شما" php -S 127.0.0.1:8080 -t .
```

> برای توسعهٔ وب لوکال هیچ تنظیم CORS لازم نیست — هر origin از نوع `localhost`،
> `127.0.0.1`، `[::1]` و `10.0.2.2` روی **هر پورتی** پذیرفته می‌شود.

## قدم‌به‌قدم چه اتفاقی می‌افتد؟ (خلاصهٔ معماری)

```
[اپ Flutter]  ──HTTP JSON──►  [PHP API]  ──PDO──►  [MySQL]
   اندروید/وب                    backend/             دیتابیس otms
```

1. کاربر لاگین می‌کند → `login.php` رمز را با `password_verify` چک می‌کند و یک
   **توکن** ۶۴ کاراکتری می‌دهد.
2. اپ توکن را در `SharedPreferences` ذخیره می‌کند و در همهٔ درخواست‌های بعدی
   در هدر `Authorization: Bearer <token>` می‌فرستد.
3. هر endpoint با `require_auth()` توکن را چک می‌کند و با `require_role()`
   سطح دسترسی را (استاد یا دانش‌آموز).
4. فایل‌های آپلودی در `backend/uploads/` ذخیره می‌شوند (نه داخل گیت).

## پیاده‌سازی روی سرور واقعی (اختیاری)

بک‌اند PHP ساده است، پس روی هر هاست اشتراکی با PHP 8 و MySQL کار می‌کند:

1. دیتابیس را از `backend/schema.sql` بسازید.
2. پوشهٔ `backend/` را آپلود کنید.
3. `OTMS_DB_*` را روی مقادیر واقعی سرور تنظیم کنید (از کد استفاده نکنید).
4. اپ را با آدرس همان سرور بیلد کنید:

```bash
flutter build apk --dart-define=OTMS_API_BASE=https://example.com/otms/backend
flutter build web --dart-define=OTMS_API_BASE=https://example.com/otms/backend
```

برای نسخهٔ وب، خروجی در `build/web/` است؛ محتوایش را کنار `backend/` در سرور
بگذارید و اصلاً پارامتر ندهید — اپ با همان originی که از آن سرو شده حرف می‌زند.

> ⚠️ قبل از انتشار عمومی، بخش **Security notes** در README اصلی را بخوانید:
> تغییر رمز دیتابیس، HTTPS، و حذف `usesCleartextTraffic` از manifest اندروید.

## سوال‌های پرتکرار

**آیا هر بار باید `--dart-define` بزنم؟**
فقط برای وب (چون پورت dev server تصادفی است) و برای گوشی واقعی. روی شبیه‌ساز
اندروید و دسکتاپ لازم نیست.

**چرا روی Chrome کار می‌کند ولی روی گوشی نه؟**
چون آدرس `localhost` روی گوشی یعنی خود گوشی، نه کامپیوتر شما. IP واقعی
کامپیوتر را بدهید (`ipconfig`).

**می‌توانم نام پوشه را به جای `OTMS1` چیز دیگری بگذارم؟**
بله، ولی هر بار باید آدرس کامل را با `--dart-define` بدهید.

**داده‌هایم را چطور ریست کنم؟**
`schema.sql` را دوباره import کنید — جداول را drop و از نو می‌سازد (روی
دیتابیس `otms`). ⚠️ همهٔ داده‌ها پاک می‌شود.

**تست‌ها روی دیتابیس اصلی اثر می‌گذارند؟**
هر اجرا یک کلاسِ تستی جدا می‌سازد و کاری به داده‌های شما ندارد. ولی چون
`schema.sql` در ابتدای برخی تست‌ها اجرا می‌شود، اگر دستی اجرایش کنید همه چیز
ریست می‌شود.
