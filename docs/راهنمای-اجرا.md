# راهنمای اجرای OTMS روی سیستم خودتان

این نسخه یک برنامهٔ واقعی «کلاینت + سرور» است: Flutter رابط کاربری را اجرا
می‌کند و PHP/MariaDB داده را نگه می‌دارند. فقط بازکردن فایل HTML یا اجرای Flutter
بدون API کافی نیست.

## مسیر پیشنهادی برای ویندوز (XAMPP)

### ۱) پیش‌نیازها

- XAMPP با PHP 8.2 یا جدیدتر و MySQL/MariaDB
- Flutter 3.47.6 یا نسخهٔ stable سازگار
- Chrome برای تست سریع؛ Android Studio برای گوشی/شبیه‌ساز

افزونه‌های `pdo_mysql` و `mbstring` در `php.ini` باید فعال باشند. پس از تغییر،
Apache را Restart کنید.

### ۲) ساخت دیتابیس تازه

در phpMyAdmin یک دیتابیس با نام `otms` و collation برابر
`utf8mb4_unicode_ci` بسازید. سپس فقط فایل `backend/schema.sql` را Import کنید.
اگر دیتابیس قدیمی و واقعی دارید، schema تازه را روی آن Import نکنید؛ بخش مهاجرت
در README را بخوانید.

### ۳) تنظیم PHP

پروژه را مثلاً در `C:\xampp\htdocs\otms` قرار دهید. فایل زیر را بسازید:

```text
C:\xampp\htdocs\otms\config\otms.env
```

نمونهٔ محلی:

```dotenv
OTMS_APP_ENV=local
OTMS_APP_KEY=یک-رشته-تصادفی-طولانی-حداقل-۳۲-کاراکتر
OTMS_DB_HOST=127.0.0.1
OTMS_DB_PORT=3306
OTMS_DB_NAME=otms
OTMS_DB_USER=root
OTMS_DB_PASS=
OTMS_PUBLIC_BASE_URL=http://127.0.0.1/otms/backend
OTMS_STORAGE_PATH=C:\xampp\otms-private\uploads
OTMS_ALLOWED_ORIGINS=http://127.0.0.1:3000,http://localhost:3000
OTMS_TRUST_PROXY=0
OTMS_DEMO_MODE=1
OTMS_ALLOW_TEACHER_REGISTRATION=1
OTMS_LIVE_PROVIDER=jitsi
OTMS_JITSI_BASE_URL=https://meet.jit.si
```

پوشهٔ `C:\xampp\otms-private\uploads` را بسازید. این پوشه عمداً داخل `htdocs`
نیست. حالا این آدرس باید JSON سالم برگرداند:

```text
http://127.0.0.1/otms/backend/api/v1/health.php
```

### ۴) اجرای Flutter Web

```powershell
cd C:\xampp\htdocs\otms\otms_flutter
flutter pub get
flutter run -d chrome --web-port=3000 `
  --dart-define=OTMS_API_BASE=http://127.0.0.1/otms/backend/api/v1 `
  --dart-define=OTMS_APP_MODE=development
```

### ۵) اجرای Android Emulator

آدرس `127.0.0.1` داخل emulator به خود emulator اشاره دارد. برای XAMPP روی همان
کامپیوتر از `10.0.2.2` استفاده کنید:

```powershell
flutter run -d emulator-5554 `
  --dart-define=OTMS_API_BASE=http://10.0.2.2/otms/backend/api/v1 `
  --dart-define=OTMS_APP_MODE=development
```

نسخهٔ release اندروید HTTP بدون رمزنگاری را قبول نمی‌کند؛ انتشار واقعی باید
HTTPS داشته باشد.

## لینوکس/macOS بدون XAMPP

```bash
mysql -u root -p -e 'CREATE DATABASE otms CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci'
mysql -u root -p otms < backend/schema.sql
mkdir -p config "$HOME/otms-storage/uploads"
cp backend/.env.example config/otms.env
# config/otms.env را برای local و مسیرهای سیستم خودتان ویرایش کنید
php -S 0.0.0.0:8080 -t backend
```

در ترمینال دوم:

```bash
cd otms_flutter
flutter pub get
flutter run -d chrome \
  --dart-define=OTMS_API_BASE=http://127.0.0.1:8080/api/v1 \
  --dart-define=OTMS_APP_MODE=development
```

## دادهٔ نمونهٔ محلی

فقط روی دیتابیس تازه و غیرتولیدی:

```bash
mysql -u root -p otms < tools/demo_seed.sql
```

ورودها:

- `teacher@otms.test` / `password`
- `student@otms.test` / `password`

در دمو آنلاین این seed استفاده نمی‌شود؛ دکمهٔ **Try demo** یک sandbox جدا و
منقضی‌شونده می‌سازد.

## تست‌ها

برای تست‌های API دو دیتابیس تمیز جدا (`otms_test` و `otms_security`) از روی
`backend/schema.sql` بسازید و سپس:

```bash
OTMS_DB_NAME=otms_test bash tools/api_test.sh
OTMS_DB_NAME=otms_security bash tools/api_security_test.sh
cd otms_flutter
flutter analyze
flutter test
```

اسکریپت‌های API خودشان PHP development server را روشن و خاموش می‌کنند.

## خطاهای رایج

- **`could not find driver`**: افزونهٔ PDO MySQL فعال نیست.
- **`Call to undefined function mb_*`**: افزونهٔ `mbstring` فعال نیست.
- **CORS در مرورگر**: origin دقیق مرورگر را در `OTMS_ALLOWED_ORIGINS` اضافه کنید
  و سرور PHP را دوباره اجرا کنید.
- **گوشی API را نمی‌بیند**: از IP شبکهٔ کامپیوتر استفاده و پورت Apache/PHP را در
  فایروال باز کنید؛ جزئیات در `اجرا-روی-گوشی.md` است.
- **ثبت‌نام معلم در production رد می‌شود**: این رفتار امنیتی است؛ دعوت یک‌بارمصرف
  بسازید یا فقط در local مقدار `OTMS_ALLOW_TEACHER_REGISTRATION=1` بگذارید.
- **Live در production خطای تنظیمات می‌دهد**: JaaS لازم است. `meet.jit.si` فقط
  برای توسعهٔ غیرتولیدی مجاز است.
