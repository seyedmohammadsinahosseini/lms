# اجرای OTMS روی گوشی Android واقعی

## قبل از شروع

1. Flutter و Android Studio/JDK را نصب کنید.
2. USB debugging گوشی را فعال کنید.
3. API و MariaDB را طبق `راهنمای-اجرا.md` روی کامپیوتر روشن کنید.
4. گوشی و کامپیوتر را به یک Wi‑Fi وصل کنید.

## روش Wi‑Fi

IP محلی کامپیوتر را پیدا کنید:

```powershell
ipconfig
```

مثلاً اگر IPv4 برابر `192.168.1.20` و پروژه در XAMPP است، ابتدا همین آدرس را در
مرورگر خود گوشی باز کنید:

```text
http://192.168.1.20/otms/backend/api/v1/health.php
```

اگر باز نشد، Apache را روی همهٔ interfaceها گوش‌ده کنید و در Windows Firewall
برای شبکهٔ Private اجازهٔ ورودی پورت 80 بدهید. فایروال را کامل خاموش نکنید.

سپس:

```powershell
cd otms_flutter
flutter devices
flutter run -d DEVICE_ID `
  --dart-define=OTMS_API_BASE=http://192.168.1.20/otms/backend/api/v1 `
  --dart-define=OTMS_APP_MODE=development
```

HTTP محلی فقط در build نوع debug مجاز شده است. manifest اصلی release همچنان
cleartext را رد می‌کند.

## روش USB با `adb reverse`

این روش به IP و بازکردن فایروال نیاز ندارد. اگر PHP روی پورت 8080 است:

```bash
adb reverse tcp:8080 tcp:8080
flutter run -d DEVICE_ID \
  --dart-define=OTMS_API_BASE=http://127.0.0.1:8080/api/v1 \
  --dart-define=OTMS_APP_MODE=development
```

بعد از قطع کابل باید `adb reverse` را دوباره اجرا کنید.

## نکات آزمون روی گوشی

- صفحه‌ها را در حالت portrait و landscape ببینید.
- انتخاب و آپلود فایل واقعی را امتحان کنید.
- بازشدن لینک دانلود امضاشده را آزمایش کنید.
- خروج و ورود دوباره را امتحان کنید تا Secure Storage بررسی شود.
- Live را هم با public Jitsi در محیط local تست کنید. اجرای production به JaaS
  نیاز دارد.

## ساخت APK نصب‌شدنی

برای debug:

```bash
cd otms_flutter
flutter build apk --debug \
  --dart-define=OTMS_API_BASE=https://YOUR-HOST/api/v1 \
  --dart-define=OTMS_APP_MODE=development
```

برای APK نهایی از debug key استفاده نکنید. راهنمای کامل و اسکریپت امن در
`انتشار-اندروید.md` است.

## عیب‌یابی کوتاه

- `No devices`: کابل داده، مجوز RSA گوشی و خروجی `adb devices` را بررسی کنید.
- `Connection refused`: اول health URL را در مرورگر گوشی باز کنید.
- خطای cleartext در release: طبیعی است؛ API آنلاین باید HTTPS باشد.
- API روی Chrome کار می‌کند ولی روی گوشی نه: معمولاً IP اشتباه یا فایروال است.
- Gradle حافظه کم دارد: build نهایی را با GitHub Actions یا دستگاهی با RAM بیشتر
  اجرا کنید؛ CI پروژه Android debug را هم کامپایل می‌کند.
