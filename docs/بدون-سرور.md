# آیا LMS بدون سرور اجرا می‌شود؟

خیر؛ نسخهٔ فعلی و قابل انتشار LMS عمداً API واقعی PHP و MariaDB دارد. قابلیت‌هایی
مثل ثبت‌نام، مجوز یک‌بارمصرف عضویت، فایل خصوصی، snapshot آزمون، تصحیح، نسخه‌های
تکلیف، Q&A و Live بین چند کاربر به یک مرجع سروری نیاز دارند.

گزینهٔ `LmsApi` در Flutter یک مرز معماری و seam تست است؛ وجود آن به معنی پیاده‌شدن
SQLite/offline backend نیست. حذف API، جایگزین‌کردن آن با دادهٔ hard-code یا پنهان
کردن قابلیت‌ها راه‌اندازی معتبر این پروژه محسوب نمی‌شود.

## راه‌های بدون هزینه

### اجرای محلی

PHP و MariaDB را روی کامپیوتر اجرا کنید و گوشی را با Wi‑Fi یا `adb reverse` وصل
کنید. این راه رایگان است اما فقط وقتی کامپیوتر روشن و در دسترس باشد کار می‌کند.
راهنما: `راهنمای-اجرا.md` و `اجرا-روی-گوشی.md`.

### دمو آنلاین رزومه

طرح انتخاب‌شده Flutter Web + PHP + MySQL روی یک میزبان رایگان واقعی است: Foojan
در صورت عبور از بررسی سازگاری، و Serv00 به‌عنوان fallback. این معماری server
واقعی با محدودیت منابع است، نه اجرای بدون سرور. مراحل در
`استقرار-رایگان.md` آمده است.

### APK

APK فقط کلاینت را بسته‌بندی می‌کند؛ دیتابیس PHP را داخل APK نمی‌گذارد. APK نهایی
باید با `LMS_API_BASE` یک API عمومی HTTPS ساخته شود.

## اگر بعداً offline واقعی لازم شد

این یک feature مستقل و بزرگ است: SQLite، صف همگام‌سازی، حل تعارض، cache فایل،
رمزنگاری محلی و تست migration لازم دارد. این قابلیت در نسخهٔ فعلی ادعا نشده است
تا رفتار ناقص یا از دست رفتن داده به کاربر تحمیل نشود.
